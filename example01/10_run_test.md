## 10.1 최종 파일 구조 확인

실행 전 아래 파일 구조가 완성되었는지 확인합니다.

```
sg90-servo-viewer/
├── server.js              ✅ 07단계에서 작성
├── package.json           ✅ 초기화 완료
└── public/
    ├── index.html         ✅ 08단계에서 작성
    ├── analyze_glb.html   ✅ 06단계에서 수정
    └── sg90_servo.glb     ✅ 05단계에서 Blender로 생성
```

```bash
# 터미널에서 확인
ls -lh sg90-servo-viewer/public/

# 기대 출력:
# -rw-r--r--  index.html         (10~15KB)
# -rw-r--r--  analyze_glb.html   (3~5KB)
# -rw-r--r--  sg90_servo.glb     (500KB~3MB)
```


## 10.4 테스트 시나리오

### 테스트 1: 모델 로딩

```
확인 항목:
□ 로딩 스피너가 표시됨
□ 로딩 중... XX% 가 진행됨
□ 로딩 완료 후 SG90 3D 모델이 뷰포트에 표시됨
□ 상태 표시줄에 "✅ 모델 로드 완료" 메시지가 나타남
□ 모델이 그리드 위에 올바르게 놓여 있음
```

### 테스트 2: OrbitControls 카메라 조작

```
확인 항목:
□ 마우스 좌버튼 드래그 → 3D 모델이 회전됨
□ 마우스 우버튼 드래그 → 카메라가 이동됨
□ 마우스 스크롤 → 줌 인/아웃
□ 더블클릭 → 카메라 초기위치로 복귀
```

### 테스트 3: 슬라이더 제어

```
확인 항목:
□ 슬라이더를 0° 쪽으로 이동 → 혼이 왼쪽으로 회전
□ 슬라이더를 180° 쪽으로 이동 → 혼이 오른쪽으로 회전
□ 현재 각도 표시가 슬라이더 값과 일치
□ 혼이 본체에 고정된 채 제자리 회전 (공전하지 않음)
```

### 테스트 4: 프리셋 버튼

```
확인 항목:
□ [0°] 클릭 → 혼이 0° 위치로 이동 + 버튼 활성화(하이라이트)
□ [45°] 클릭 → 혼이 45° 위치로 이동
□ [90°] 클릭 → 혼이 중립(90°)으로 이동
□ [135°] 클릭 → 혼이 135° 위치로 이동
□ [180°] 클릭 → 혼이 180° 위치로 이동
```

### 테스트 5: 스윕 모드

```
확인 항목:
□ [스윕] 클릭 → 혼이 0°~180°를 자동으로 왕복
□ 슬라이더가 왕복 이동에 따라 자동으로 움직임
□ [⏹ 정지] 클릭 → 스윕 정지
□ 정지 후 슬라이더로 수동 제어 가능
```

### 테스트 6: 회전 속도 변경

```
확인 항목:
□ 속도 [느림] 선택 후 프리셋 클릭 → 혼이 천천히 이동
□ 속도 [빠름] 선택 후 프리셋 클릭 → 혼이 빠르게 이동
□ 속도 [즉시] 선택 후 프리셋 클릭 → 혼이 즉시 목표 위치로 이동
```

## 10.5 서버 로그 확인

테스트 중 서버 터미널에서 요청 로그를 확인합니다.

```
[10:00:05] GET /
  ✅ 200 text/html; charset=utf-8 (12.3KB)

[10:00:05] GET /sg90_servo.glb
  ✅ 200 model/gltf-binary (1248.5KB)

[10:00:10] GET /analyze_glb.html
  ✅ 200 text/html; charset=utf-8 (4.1KB)
```

> GLB 파일의 Content-Type이 `model/gltf-binary` 인지 반드시 확인합니다.  
> `application/octet-stream` 이면 MIME 매핑 오류입니다.

## 10.6 네트워크 접속 테스트 (스마트폰 / 태블릿)

같은 Wi-Fi 네트워크에서 스마트폰으로 접속해 테스트합니다.

```bash
# 서버 터미널에 표시된 네트워크 IP 사용
# 예: http://192.168.1.105:3030

스마트폰 브라우저(Chrome/Safari)에서:
→ http://192.168.1.105:3030 접속
→ 터치 드래그로 3D 모델 회전 가능
→ 슬라이더로 서보 제어 가능
```

## 10.7 전체 완성 체크리스트

```
환경 준비
□ Blender 3.6 LTS 설치 완료
□ Node.js 18.x 설치 완료
□ FreeCAD/CAD Assistant 설치 완료

파일 변환
□ STEP → OBJ/GLB 변환 완료
□ Blender에서 파트 분리 완료
□ 오브젝트 이름 부여 완료 (sg90_body, sg90_horn …)
□ sg90_horn Origin 회전축 중심으로 설정 완료
□ 재질(Material) 설정 완료
□ sg90_servo.glb 내보내기 완료

GLB 검증
□ analyze_glb.html로 모든 파트 이름 확인 완료
□ sg90_horn ✅ 확인

서버/뷰어
□ server.js 작성 완료
□ public/index.html 작성 완료
□ node server.js 정상 시작 확인

테스트
□ 모델 로딩 성공 확인
□ OrbitControls 정상 동작 확인
□ 슬라이더 → 혼 회전 정상 확인
□ 프리셋 버튼 동작 확인
□ 스윕 모드 동작 확인
□ 속도 변경 동작 확인
```
