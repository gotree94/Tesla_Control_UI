## 1.1 프로젝트 목표

이 프로젝트는 **SolidWorks로 설계된 SG90 서보모터 3D 모델**을 웹 브라우저에서  
인터랙티브하게 제어하는 시스템을 단계별로 구축하는 교육용 가이드입니다.

```
목표 1 : SolidWorks STEP 파일의 구조를 이해한다
목표 2 : Blender를 이용해 GLB 포맷으로 변환하는 전 과정을 익힌다
목표 3 : GLB 파일 구조를 코드로 분석 · 검증하는 방법을 배운다
목표 4 : Node.js 웹 서버로 3D 모델을 브라우저에 제공하는 구조를 이해한다
목표 5 : Three.js로 3D 모델의 특정 파트를 코드로 제어한다
```

## 1.2 SG90 Micro Servo 스펙

### 물리 스펙

```
제조사  : Tower Pro
모델명  : SG90 Micro Servo 9g
전압    : 4.8V ~ 6.0V DC
토크    : 1.8 kgf·cm  @ 4.8V
          2.2 kgf·cm  @ 6.0V
속도    : 0.10 sec/60°  @ 4.8V (부하 없음)
          0.08 sec/60°  @ 6.0V
회전각  : 0° ~ 180°
무게    : 9g
```

### 외형 치수 (mm)

```
      ←─── 22.2 ───→
  ┌───────────────────┐   ↑
  │  ○  SG90  SERVO  │   │  31.0
  │  (기어·PCB 내장) │   │  (마운팅 귀 포함)
  ├────┬──────────┬───┤   ↓
  │    │  mount   │   │   ↑ 2.5 (마운팅 귀 두께)
  └────┴──────────┴───┘
       ←─── 12.0 ───→
       ↑ 마운팅 귀 폭

혼(Horn) 샤프트:
  - 위치 : 본체 상단 중앙
  - 직경 : ∅4.8mm (스플라인 샤프트)
  - 높이 : 본체 상단에서 +3.0mm
```

### PWM 제어 신호 (실제 하드웨어 연결 시 참고)

```
주파수 : 50Hz (주기 20ms)
최소펄스 : 500μs  → 0°
중립펄스 : 1500μs → 90°
최대펄스 : 2400μs → 180°

커넥터 핀 배치 (JR 방향):
  ① 갈색(Brown)  → GND
  ② 빨간색(Red)  → VCC (4.8~6V)
  ③ 주황색(Orange) → 신호(Signal / PWM)
```

## 1.3 원본 STEP 파일 파트 구성

업로드된 `SG90 - Micro Servo 9g - Tower Pro.STEP` 파일을 분석한 결과:

```
ISO-10303-21 (STEP AP214)
SolidWorks 2018 생성
파일 크기: 5.3MB / 66,691줄
```

**어셈블리 계층 구조:**

```
SG90 - Micro Servo 9g - Tower Pro   ← 최상위 어셈블리 (#1989)
├── Part_1  (.1_Pe…)                ← 서보 본체 하우징
├── Part_2  (.2_Pe…)                ← 혼 / 출력 샤프트부
├── Part_3  (.3_Pe…)                ← 내부 기어 케이스 또는 하단 캡
├── Part_4  (.4_Pe…)                ← 상단 커버
├── Screw_1 (.5_ M2×8)             ← ISO 7045 십자 나사 M2×8
└── Screw_2 (.6_ M2×4)             ← ISO 7045 십자 나사 M2×4
```

> 💡 각 파트의 정확한 형상은 Blender 임포트 후 시각적으로 확인합니다.  
> → **[04_blender_import.md](./04_blender_import.md)**

## 1.4 전체 작업 흐름

```
STEP 1 ─ 환경 준비
│   Blender 3.6 설치 확인
│   Node.js 18 설치 확인
│
STEP 2 ─ STEP 파일 분석 (SolidWorks 시점)
│   파트 구성 파악
│   회전 파트(혼) 식별
│   원점(Origin) 전략 수립
│
STEP 3 ─ Blender 임포트 & 확인
│   STEP 파일 임포트
│   씬 트리에서 파트 확인
│   형상이 올바른지 뷰포트에서 검토
│
STEP 4 ─ GLB 변환 작업
│   파트 분리 (Separate by Loose Parts)
│   오브젝트 이름 부여
│   혼(Horn) Origin → 회전축 중심으로 재설정
│   재질(Material) PBR 설정
│   GLB 내보내기
│
STEP 5 ─ GLB 구조 검증
│   Node.js 서버 실행
│   analyze_glb.html로 파트 이름 확인
│   메시 수 · 버텍스 수 확인
│
STEP 6 ─ 3D 뷰어 구현
│   Node.js server.js 작성
│   public/index.html (Three.js) 작성
│   GLTFLoader로 sg90_servo.glb 로드
│   OrbitControls 설정
│
STEP 7 ─ 서보 제어 UI
│   슬라이더 → 혼 rotation.y
│   프리셋 버튼 (0°, 45°, 90°, 135°, 180°)
│   스윕 자동 왕복
│   각도 보간(Lerp) 애니메이션
│
STEP 8 ─ 실행 & 테스트
    node server.js
    http://localhost:3030 접속
    슬라이더로 혼 회전 확인
```
